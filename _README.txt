Technical SEO Skills-md by Afeez Adebayo

16 skills as single Markdown files in one folder, for uploading many at once (for example to a Claude Project, a ChatGPT project or custom GPT, a knowledge base or a document store).

Each file is the full SKILL.md, renamed to <skill-name>.md.
For Claude Code, Codex and other Agent Skills tools, use the folder-per-skill download instead: those tools need each skill in its own folder named SKILL.md.
